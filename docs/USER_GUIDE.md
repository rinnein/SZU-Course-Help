# 深大抢课助手 3.4.0 使用手册

- 适用项目：SZU Course Help
- 适用人群：希望直接下载并运行、不熟悉 Python 或命令行的用户
- 项目主页：https://github.com/Weeye-hua/SZU-Course-Help
- 下载页面：https://github.com/Weeye-hua/SZU-Course-Help/releases/latest

> 本项目是非官方工具，与深圳大学及其选课系统运营方无隶属或授权关系。请遵守学校规定。预选阶段由学校抽签，程序会禁止启动自动抢课。

## 一、先选择正确的下载包

打开 GitHub Releases 页面，在最新版本底部的 Assets 中按系统下载：

- Windows 10/11 64 位：`SZU-Course-Help-v3.4.0-windows-x64.zip`
- macOS Apple 芯片：`SZU-Course-Help-v3.4.0-macos-arm64.zip`
- macOS Intel 芯片：`SZU-Course-Help-v3.4.0-macos-x64.zip`
- Linux 64 位：`SZU-Course-Help-v3.4.0-linux-x64.zip`
- 源码仅供开发者使用，普通用户不要下载 Source code 压缩包。

下载后必须先完整解压。不要在压缩包预览窗口内直接运行程序，也不要只把主程序单独拖出来，否则 OCR 模型和依赖文件可能丢失。

每个发布包都包含：

- 可执行程序及其运行依赖
- `使用手册.md`
- `使用手册.pdf`
- `更新记录.md`
- `LICENSE`
- 平台启动脚本

## 二、Windows 使用方法

1. 右键下载的 ZIP，选择“全部解压缩”。
2. 打开解压后的文件夹。
3. 双击 `启动抢课助手.bat`，或直接双击 `SZU-Course-Help.exe`。
4. 保持弹出的终端窗口开启。关闭终端就会停止本地网页服务。
5. 程序会自动打开浏览器；没有自动打开时，复制终端显示的 `http://127.0.0.1:端口/login` 地址到浏览器。

Windows SmartScreen 可能提示“Windows 已保护你的电脑”，原因是当前发布包未购买商业代码签名证书。请先确认下载地址确实属于本项目 Release，再选择“更多信息”并决定是否运行。不要从群文件、网盘或陌生链接下载改版程序。

## 三、macOS 使用方法

### Apple 芯片还是 Intel

点击屏幕左上角苹果菜单，打开“关于本机”：

- 显示 Apple M1、M2、M3、M4 等芯片，下载 `macos-arm64`。
- 显示 Intel 处理器，下载 `macos-x64`。

### 启动步骤

1. 双击 ZIP 完成解压。
2. 双击文件夹内的 `启动抢课助手.command`。
3. 若 macOS 阻止运行，前往“系统设置 - 隐私与安全性”，确认文件来自本项目 Release 后选择仍要打开。
4. 仍无法运行时，打开“终端”，将解压后的文件夹拖入终端，并执行：

```bash
chmod +x ./启动抢课助手.command ./SZU-Course-Help
xattr -dr com.apple.quarantine .
./启动抢课助手.command
```

当前发布程序未进行 Apple Developer ID 签名和公证，因此 Gatekeeper 可能显示安全提示。不要为了运行来历不明的副本而关闭整个系统的安全功能。

## 四、Linux 使用方法

1. 解压 `linux-x64.zip`。
2. 在该目录打开终端。
3. 执行：

```bash
chmod +x ./启动抢课助手.sh ./SZU-Course-Help
./启动抢课助手.sh
```

也可以在支持可执行脚本的桌面环境中双击 `启动抢课助手.sh`。不同发行版的文件管理器策略不同，终端启动方式最稳定。

若提示缺少系统动态库，请优先使用较新的 Ubuntu、Debian、Fedora 或兼容发行版。Linux 发布包由 GitHub 的 Ubuntu x64 环境构建，不保证兼容过旧的 glibc。

## 五、第一次启动

程序启动后会在终端显示项目名称，并自动启动本地服务、打开浏览器登录页。

1. 在浏览器登录页输入自己的学号，只允许 6 至 12 位数字。
2. 输入深圳大学选课系统密码。
3. 按验证码上方提示的四个汉字顺序，依次点击图片中的对应文字。
4. 确认四个点击位置后点击登录。首次登录时程序会自动在当前目录生成 Ed25519 签名密钥，并在登录过程中自动签发并校验该学号绑定的 Card Key V3，界面不展示卡密。

如果学校当前没有开放验证码接口，页面会显示“当前时段暂无验证码”，本次加载随即停止，不会一直转圈或在后台自动循环。此时登录按钮保持禁用；等待学校开放或维护结束后，再点击“重新获取验证码”。这不表示密码或 Card Key 错误。

Card Key 只在本机验证，不会发送给学校。学校密码只保存在当前程序进程内存中，用于会话过期后的自动重登录，不写入本地数据库。

## 六、页面与选课阶段

程序不按固定日期猜测阶段，而是读取学校返回的批次名称。

### 预选阶段

- 可以浏览课程和整理本地清单。
- 不允许启动自动抢课。
- 预选结果由学校抽签，使用自动刷新没有意义。

### 复选、正选、补选或补退选阶段

- 学校批次明确匹配允许阶段后，才会启用“启动抢课”。
- 启动前必须再次确认阶段。
- 后端还会再次请求学校批次，确认失败时不会启动。

### 未开放、已结束或未知阶段

- 页面显示课程目录暂不可用或暂未读取到批次。
- 本地清单会保留。
- 点击“重新检查开放状态”只刷新批次，不会偷偷提交课程。
- 批次名称未知时采用保守策略，禁止启动。

## 七、浏览课程与整理清单

左侧或手机顶部可以切换本班推荐、方案内、方案外、校公选、体育和慕课。

- “可加入”：可以放入本地清单。
- “已满”：可以加入候补清单，开放阶段中继续尝试。
- “时间冲突”：不能加入。
- “已选”：不能重复加入。
- 辅修课程当前不支持，请使用学校官方系统处理。

“加入清单”不会立即向学校提交课程。只有在允许阶段中，用户打开选课清单、确认阶段并点击启动后，后台任务才开始。

### 切换校区

课程工具栏支持粤海、丽湖、深大附属医院、技术大学、香港和深理光明六个校区。首次登录使用学校返回的默认校区；之后可以在课程工具栏中手动切换。

- 切换校区只改变随后读取的课程目录，不会执行选课或退课。
- 每门加入清单的课程会保存当时的校区代码。之后切换到其他校区继续浏览，不会修改已经在清单中的课程。
- 课程总量、搜索结果、满额和冲突状态按学号、批次和校区分别缓存，不会混用不同校区的数据。
- OCR 自动重登录和批次刷新不会重置用户手动选择的校区。
- 开启“缓存模式”后优先显示最近一次成功且非空的课程列表，并每 30 秒后台刷新；刷新失败或返回空列表时保留当前内容。`TJKC` 和 `FANKC` 会自动持久化完整目录，选课批次切换、学校系统故障或登录失败时仍可在工作台本地查阅曾经加载过的课程；选课清单也可在未登录时只读查看。该开关只在当前页面会话内有效。

### 查看课表

点击顶部“我的课表”可读取学校当前已选课程，并按周一至周日、1 至 14 节展示。此功能只查询数据，不会执行选课、退课或清单修改。

- 只要学校返回的排课文字包含星期和具体节次，课程就会进入网格。
- 多个星期、多个时间段、不同起止周以及单双周都会分别展示；周次信息不会阻止课程进入课表。
- 同一时段确实存在多个课程片段时才会并排显示，其他时段保持完整宽度。
- 课程名称、周次、地点和教师会完整换行，网格行高会按内容自动增加。
- 只有缺少星期、缺少具体节次或节次超出 1 至 14 的课程，才会出现在课表下方的未安排列表中，并保留学校原始时间地点供核对。

### 启动后的暂停、继续和移除

- 点击“暂停任务”后，页面可能短暂显示“正在暂停”。这表示当前学校请求尚未结束，此时不能移除仍在排队的课程。
- 页面显示“已暂停”后，后台已停在请求间隙，可以安全移除不再需要的待处理课程；其余课程和尝试次数会保留。
- 已成功或已停止的终态课程不会再次提交，可以直接从本地清单移除。
- 删除课程会同步移除实时进度中的对应项目。删除最后一门待处理课程后，任务会自动结束。
- 点击“继续任务”前，程序会重新检查登录状态和学校批次；当前阶段不允许或无法确认时，任务继续保持暂停。

学校明确返回“当前时间不在选课开放时间范围内”时，程序只提交一次并自动暂停。等待学校实际开放后再点击“继续任务”。满员响应则会继续轮询，不受未知响应保护阈值限制。

学校偶尔可能返回 `NullPointer` 或其他不符合接口协议的内容。未知响应按课程分别统计，默认连续 200 次才保护性暂停；中间只要收到一次成功、满员、繁忙等可识别结果，该课程计数就会清零。需要调整时可在启动前设置环境变量 `COURSE_SELECT_UNKNOWN_RESPONSE_LIMIT`，非法值、零或负数会回退到 200。不要设置得过低，也不建议完全取消保护。

## 八、会话过期与 OCR 自动重登录

学校登录状态可能在运行一段时间后过期。程序检测到明确的过期响应时，会自动：

1. 获取一张新点击验证码。
2. 识别顶部目标文字和底部候选字符。
3. 计算四个点击坐标。
4. 使用当前进程内存中的学号和密码重新登录。
5. 刷新 token、Cookie 和学校批次。
6. 从未完成课程继续运行。

每次自动恢复最多尝试 50 张验证码。50 次上限只用于可以继续获取验证码但识别失败的情况；学校明确返回验证码接口未开放时会立即停止，不会连续请求 50 次。OCR 依赖缺失、识别持续失败或学校拒绝登录时，页面会要求手动重新登录。

自动恢复期间，工作台会显示“正在自动重新登录”和当前说明。恢复成功后页面会刷新会话状态并继续未完成任务；连续失败后任务保持暂停，清单不会丢失，可以先手动登录再继续。

## 九、常见问题

### 浏览器没有自动打开

保持终端开启，把终端中的本地访问地址完整复制到 Chrome、Edge、Firefox 或 Safari。

### 登录页显示“当前时段暂无验证码”

学校当前没有返回可用的登录验证码，常见于非选课时间、阶段切换或系统维护。程序已经停止本次加载，不会在后台反复请求。等待学校开放后点击“重新获取验证码”；如果学校官方页面也无法获取验证码，请以官方开放安排为准。

### 验证码显示超时、网络异常或响应异常

本次加载已经停止。确认终端窗口仍在运行并检查网络，然后点击“重新获取验证码”。持续失败时先查看学校官方系统是否可用，不要连续快速点击刷新。

### 页面显示“暂未读取到选课批次”

登录可能已经成功，但学校当前没有返回有效批次。点击“重新检查开放状态”。这不等于密码错误，本地清单也不会丢失。

### 页面显示“课程目录读取失败”

可能是学校系统拥堵、接口超时或返回格式暂时变化。点击“刷新课程”。同一页之前加载成功过时，页面会继续显示上次成功结果。

### 刷新后仍然显示非开放期

程序以学校当前返回的批次为准。等待学校正式开放后再次检查，不要修改源码绕过阶段保护。

### 端口 8000 被占用

程序会自动尝试后续端口，请使用终端实际显示的地址。

### 双击后窗口立即关闭

使用发布包中的平台启动脚本，它会在异常时保留提示。也可以在终端中运行主程序查看完整错误。

### 页面还是旧 UI

关闭旧程序，重新启动当前 Release，并使用本次终端打印的普通 `/login` 地址。

### 暂停或失败后无法移除课程

先确认页面状态。显示“正在暂停”时，程序正在等待当前学校请求结束；变为“已暂停”后，活动课程的“移除”会自动启用。已停止课程可以直接移除，无需暂停其他课程。如果按钮仍是旧状态，请确认使用的是 v3.4.0 或更新版本，并重新打开本次终端输出的页面地址。

### 自动重新登录显示“OCR 依赖不可用”

先确认使用的是 v3.4.0 或更新版本。本版本兼容 `ddddocr 1.6.1` 在不同平台上的新旧导出方式，官方 Release 也会在每个平台打包前真实初始化 OCR 引擎。源码运行请使用文档指定的 Python 3.13，并重新执行 `python -m pip install -r requirements.txt`；不要混用其他项目的虚拟环境。仍然失败时请保留完整终端日志，并在反馈前删除其中的学号、密码、Cookie、token 和本机路径等敏感信息。

### 杀毒软件提示未知程序

OCR 和 ONNX Runtime 会携带较多本地模型及动态库，未签名的新程序也可能触发启发式提示。请只从项目官方 Release 下载，不要直接忽略来自未知来源的警告。

## 十、数据、密钥与卸载

默认情况下，程序目录会产生：

- `card_signing_private.pem`：Card Key 私钥，绝不能分享。
- `card_signing_public.pem`：与当前安装身份配对的公钥。
- `course_enroll.db`：本地课程清单和任务状态。
- OCR 临时图片与日志。

备份或移动程序时，应把整个解压目录作为一个整体处理。丢失 Card Key 密钥后，旧 Card Key 将无法继续验证。

卸载时先退出程序，再删除整个解压目录。希望保留 Card Key 身份和清单时，应先备份上述密钥和数据库，并妥善保管。

## 十一、安全提醒

- 只从 https://github.com/Weeye-hua/SZU-Course-Help/releases 下载。
- 不要向任何人发送学号、密码、Cookie、token、验证码截图、Card Key 或 PEM 密钥。
- 不要把程序目录上传到网盘或公开仓库，其中可能包含私钥和本地清单。
- 本软件是本地单用户程序，默认只通过 `127.0.0.1` 访问。用户主动将服务暴露到局域网或公网后造成的个人信息泄露风险不在安全边界内，请不要修改监听地址或转发端口公开服务。
- 学校接口与规则可能变化，关键选课结果请以学校官方系统为准。

## 十二、开发者源码运行

普通用户可以跳过本节。开发者可在 Python 3.14 环境中运行：

```powershell
git clone git@github.com:Weeye-hua/SZU-Course-Help.git
cd SZU-Course-Help
python -m pip install -r requirements.txt
python main.py
```

测试不会访问学校系统：

```powershell
python -m pip install -e ".[test]"
python -m ruff check .
python -m pytest -q
```
