## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.5.0 更新说明

1. 全目录读取加入进程级请求节奏控制，默认在相邻学校分页请求间等待 600ms；控制范围按账号摘要、批次和校区隔离，多个浏览器请求不会绕过间隔。
2. 学校明确返回限流提示时，前端执行有限次数的指数退避并显示当前等待状态；普通业务拒绝、登录过期和网络异常继续采用各自独立逻辑。
3. 新增课程目录本地只读缓存，缓存键覆盖账号摘要、批次、校区、课程类型与分页参数，学校未开放或暂时异常时可手动查看最近一次成功数据。
4. 缓存只写入成功且非空的完整页面，采用原子替换，并限制有效期、最长保留时间和总条目数；不保存明文学号，页面会标注缓存时间与过期状态。
5. 课程列表新增“隐藏冲突”和“隐藏已满”筛选；已选择的教学班始终保留可见，课程分组仍默认折叠。
6. 课程卡片补充课程类别、课程性质、开课单位和学分等学校返回字段；缺失字段保持为空，不用猜测值补齐。
7. 启动工作台前执行 OCR 兼容性自检，支持 `ddddocr.core` 新接口、顶层新接口和旧 `DdddOcr` 接口；异常时保留手动登录并明确提示自动重登录不可用。
8. 本地 API 增加同源来源校验；学校官方页面改为使用系统浏览器直接打开，不代理学校页面，也不在助手同源环境中执行学校脚本。
9. CI 同时覆盖 Python 3.13 和 3.14，并安装真实 OCR 依赖执行初始化测试；四个平台的 Release 构建仍会在打包前验证 OCR 引擎。
10. 本版本在严格审查后重写并整合 PR #4 的筛选、缓存、字段展示与 OCR 自检思路，以及 PR #5 的分页节奏控制；未引入代理学校页面、保存学校密码、WebVPN 或后台会话持久化逻辑。
11. 保留上一版的六校区目录、只读课表、完整目录搜索、200 次未知响应保护、任务暂停/继续、暂停后移除和可见 OCR 自动重登录行为。
12. Release 只提供各平台与源码 ZIP，不附带独立 `.sha256` 或 `SHA256SUMS.txt` 文件。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，在终端输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并手动完成点击验证码。
5. 预选、未开放、已结束和未知阶段禁止启动自动选课；只有学校返回明确允许的复选、正选、补选或补退选批次才可在二次确认后启动。

## 安全与兼容性

- 本项目暂未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 首次运行会在解压目录生成本机 Card Key 密钥和本地清单数据库，请勿公开、上传网盘或提交到 Git。
- Windows 包在 Windows x64 原生构建，两个 macOS 包分别在 Apple Silicon 与 Intel 原生构建，Linux 包在 Ubuntu 22.04 x64 构建。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停与移除、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
