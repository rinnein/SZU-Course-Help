## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.4.0 更新说明

1. 修复 macOS 等环境中 `ddddocr 1.6.1` 只在 `ddddocr.core` 导出新引擎类时，OCR 自动重登录无法初始化的问题；同时兼容顶层新 API 与旧 `DdddOcr` API。
2. 多平台 Release 构建会在打包前真实初始化 OCR 检测与识别引擎，避免依赖可安装但自动重登录运行时才失败。
3. 课程目录新增粤海、丽湖、深大附属医院、技术大学、香港和深理光明六校区切换；首次使用学校默认校区，之后保留用户手动选择。
4. 每门加入清单的课程独立保存校区代码；切换校区继续浏览不会改变已有清单课程的提交参数，旧版数据库会自动补充兼容字段。
5. 新增只读“我的课表”，把学校当前已选课程按周一至周日、1 至 14 节排入网格，不会调用选课、退课或清单修改接口。
6. 多星期、多时段、不同起止周以及单双周课程均会进入网格；只有缺少可定位星期或具体节次的课程才进入未安排列表。
7. 课表只在实际重叠时段分栏，卡片和网格会依据课程名称、周次、地点与教师内容自动增高，较长内容不再被遮挡或省略。
8. 切换课程目录或首次加载时，所有课程默认折叠，由用户点击后再展开教学班。
9. 课程搜索覆盖当前目录的全部分页，并在本地对匹配结果重新分页；目录缓存按学号、批次和校区隔离。
10. 刷新课程、切换批次、自动重登录成功和抢课任务结束后会清理过期目录结果，异常分页不会被误标为完整缓存。
11. 保留上一版的 200 次未知响应保护、任务暂停/继续、暂停后移除、关闭时段门控和可见 OCR 自动重登录行为。
12. Release 仍只提供各平台与源码 ZIP，不附带独立 `.sha256` 或 `SHA256SUMS.txt` 文件。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，在终端输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并手动完成点击验证码。
5. 预选、未开放、已结束和未知阶段禁止启动自动选课；只有学校返回明确允许的复选、正选、补选或补退选批次才可在二次确认后启动。

## 安全与兼容性

- 本项目暂未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 首次运行会在解压目录生成本机 Card Key 密钥和本地清单数据库，请勿公开、上传网盘或提交到 Git。
- Windows 包在 Windows x64 原生构建，两个 macOS 包分别在 Apple Silicon 与 Intel 原生构建，Linux 包在 Ubuntu 22.04 x64 构建。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停与移除、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
