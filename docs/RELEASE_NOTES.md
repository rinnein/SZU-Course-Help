## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.3.1 更新说明

1. 学校接口间歇返回 `NullPointer` 等未知内容时，单门课程需连续达到 200 次才保护性暂停；中间收到一次可识别结果就会清零计数。
2. 可在启动前通过 `COURSE_SELECT_UNKNOWN_RESPONSE_LIMIT` 自定义该阈值；非法值、零或负数会回退到 200。
3. 学校批次存在但实际时段尚未开放时，只提交一次请求并自动暂停，不再把“当前时间不在选课开放时间范围内”当成未知返回连续尝试。
4. 满员课程会持续公平轮询；未知响应、连续网络异常和内部异常使用独立保护逻辑，不把仍可恢复的课程永久标记为失败。
5. 清单支持暂停和继续。当前学校请求完成并安全暂停后，可以移除活动课程；已成功或已失败课程可直接移除。
6. 删除课程会同步清理实时进度；删除最后一门待处理课程后，后台任务自动收尾，不会留下无法操作的空任务。
7. 学校会话过期后，网页会显示 OCR 自动重新登录的进行中、成功和失败状态，恢复成功后继续原任务。每次恢复最多识别 50 张验证码。
8. 学校在非开放时段不提供验证码时，登录页会停止加载并提示稍后重试，不会一直转圈或自动循环请求。
9. Release 下载区仅保留各平台与源码 ZIP，不再附带独立校验文件。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，在终端输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并手动完成点击验证码。
5. 预选、未开放、已结束和未知阶段禁止启动自动选课；只有学校返回明确允许的复选、正选、补选或补退选批次才可在二次确认后启动。

## 安全与兼容性

- 本项目暂未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 首次运行会在解压目录生成本机 Card Key 密钥和本地清单数据库，请勿公开、上传网盘或提交到 Git。
- Windows 包在 Windows x64 原生构建，两个 macOS 包分别在 Apple Silicon 与 Intel 原生构建，Linux 包在 Ubuntu 22.04 x64 构建。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停与移除、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
